# Landing Page — Ayam Goreng Bawang Putih 71

Website landing page UMKM dengan konsep **Modern Premium**, warna krem dan hijau tua. Dibuat menggunakan HTML5, CSS3, JavaScript, dan Bootstrap 5 tanpa database.

## Struktur folder

```text
ayam-goreng-bawang-putih-71/
├── index.html
├── README.md
├── css/
│   └── style.css
├── js/
│   └── script.js
└── images/
    ├── logo-ayam-bawang-putih-71.jpeg
    ├── paket-ayam-goreng.jpeg
    ├── taro-latte.jpeg
    ├── daftar-harga.jpeg
    └── sambal-bunda-jennie.jpeg
```

## Cara menjalankan

1. Ekstrak file ZIP.
2. Buka folder `ayam-goreng-bawang-putih-71`.
3. Klik dua kali `index.html`, atau buka folder menggunakan Visual Studio Code lalu jalankan dengan ekstensi Live Server.
4. Koneksi internet diperlukan untuk memuat Bootstrap 5, Google Fonts, dan peta Google Maps dari CDN/layanan eksternal.

## Fitur

- Tampilan responsif untuk desktop, tablet, dan smartphone.
- Navigasi Bootstrap 5.
- Hero section dan profil usaha.
- Kartu menu dengan foto produk.
- Galeri foto produk.

- Nomor telepon yang dapat ditekan untuk menelepon.
- Peta Google Maps berdasarkan alamat yang diberikan.

## Penyesuaian

- Ubah teks, menu, dan informasi kontak di `index.html`.
- Ubah warna dan tata letak di `css/style.css` melalui variabel CSS pada bagian `:root`.
- Ubah perilaku tombol atau interaksi di `js/script.js`.
- Ganti foto di folder `images/` dengan tetap mempertahankan nama file yang digunakan HTML, atau sesuaikan alamat gambar di `index.html` dan `css/style.css`.
